Attendance records

One row per student with Course, Class, Student Number and Name, then one column per session headed like Autumn W3, holding Present, Absent or blank (not recorded). Exports add attended, recorded and percentage columns. On import, rows go to the class named in their Course and Class columns (or to the class selected above if the file has no such columns), and filled-in cells overwrite current marks.

Click a week number to open that session's register. Schedule files have one row per class with Course, Title, Type, Class, Day, Start, End, then a Location and Weeks column for each term (weeks written like 2 3 4 5 7 8 9 10 11). Importing updates classes with the same course and class number and adds new ones.

Student records

Columns: Course, Class, Student Number, Name. The export follows the class filter above. On import, each row goes to the class matching its Course and Class. If the file only has Student Number and Name, choose a class in the filter first and they are added to it. Existing students (same number in the same class) get their names updated.
